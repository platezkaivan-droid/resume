VAMOS VPN — Telegram-бот продажи VPN с веб-кабинетом

Личный проект · @haribo_vamos_vpn_bot · 2026 · работает на реальных пользователях на собственном сервере
  • Полный цикл VPN-сервиса: продажа подписок, выдача конфигов, учёт трафика и лимитов, поддержка — всё автоматизировано, один процесс бота + системные сервисы на Linux-сервере.
  • VPN-ядро AmneziaWG (обфусцированный WireGuard): userspace-демон amneziawg-go, отдельный пир-ключ и конфиг на каждого пользователя, генерация конфигов на лету при покупке.
  • Обратный сплит-туннель: AllowedIPs = «весь мир кроме РФ» (~4 600 префиксов, автогенерация кроном ежемесячно) — российские сервисы ходят с родного IP оператора, без redirect-loop анти-ботов.
  • Обход блокировок TikTok: клиентский трафик маркируется в nftables и уходит в Cloudflare WARP; QUIC/UDP-443 режется — приложения откатываются на TCP.
  • DNS-политика: dnsmasq с filter-AAAA (только IPv4) и резолвом RU-доменов через Yandex DNS — RU-трафик идёт мимо туннеля.
  • Монетизация: тарифы START / VAMOS / EL JEFE, триал 4 дня с гейтом подписки на канал, оплата CryptoBot и с внутреннего баланса, колесо удачи, рефералка (+3 дня обоим, 20% кэшбэк), автопромики в канал каждые 60 ч, новостные посты, поллинг инвойсов каждые 20 с.
  • Веб-кабинет (Telegram WebApp): Cloudflare (DDoS-защита) → nginx → Python; авторизация по initData (HMAC-SHA256), покупка тарифов, история, кнопка «Подключить» запускает AmneziaWG на телефоне.
  • Данные и эксплуатация: SQLite (users, subscriptions, payments, промики, колесо), бэкапы, статус всех сервисов и метрики за 24 ч одной командой.
Стек: Python, aiogram 3, SQLite, AmneziaWG (WireGuard), nftables, dnsmasq, Cloudflare WARP, nginx, systemd, CryptoBot

dvpn — VPN-клиент в терминале

Личный проект · 2026 · github.com/platezkaivan-droid/dvpn-get
  • Терминальный клиент на Python: импорт подписки (Clash/mihomo, base64-ссылки) и подключение прямо из консоли, одинаково на Windows и Linux, без прав администратора.
  • TUI-интерфейс: живой заголовок со статусом (узел, режим, системный прокси, трафик), таблица нод с замером пинга, сортировкой и фильтром, полоса квоты, управление профилями прямо из интерфейса.
  • Ядро mihomo: vless (Reality, xhttp, gRPC), hysteria2, trojan, vmess, shadowsocks; ядро докачивается автоматически, управление системным прокси (SOCKS5+HTTP).
  • Дистрибуция: установка одной командой (PowerShell / curl) через репозиторий dvpn-get с готовыми бинарниками на GitHub Releases, портативный режим в одной папке.
Стек: Python, mihomo (Clash), TUI, GitHub Releases
