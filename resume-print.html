VAMOS VPN — Telegram-бот продажи VPN с веб-кабинетом

Личный проект (@haribo_vamos_vpn_bot) · 2026 · работает на реальных пользователях
  • Реальные платежи: тарифы, оплата через CryptoBot и с внутреннего баланса, рефералка, колесо удачи, автопромики — сервис на автопилоте.
  • VPN-ядро AmneziaWG: userspace-демон amneziawg-go, отдельный пир-ключ на пользователя, сплит-туннель «весь мир кроме РФ» (~4 600 префиксов, автогенерация по крону).
  • Обход блокировок: TikTok-трафик маркируется в nftables и уходит в Cloudflare WARP; dnsmasq отдаёт только IPv4, RU-домены через Yandex DNS.
  • Веб-кабинет (Telegram WebApp): Cloudflare → nginx → Python, авторизация по initData (HMAC-SHA256): покупка тарифов, история, подключение одним тапом.
  • Эксплуатация: SQLite + systemd, поллинг инвойсов каждые 20 с, статус всех сервисов одной командой.
Стек: Python, aiogram 3, SQLite, AmneziaWG (WireGuard), nftables, dnsmasq, Cloudflare WARP, nginx, systemd, CryptoBot
